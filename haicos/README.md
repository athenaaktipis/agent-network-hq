# HAICoS workspace

Working area for the **Human-AI Coevolution Society (HAICoS)** — a new scholarly society
in formation, founded 2026. Website: [haicos.org](https://haicos.org).

This directory is the war-room workspace for society operations: founding roster,
website, and the inaugural conference (planned for May 2027 in Crete).

What's here:

- `CLAUDE.md` — workspace context Claude Code loads when working in this directory
  (what HAICoS is, where the source-of-truth documents live, privacy rules).

This repo is **public**. Working documents (founder roster, venue proposals,
correspondence) live in Google Drive and email, not here — this workspace holds only
pointers to them and public-safe material.
